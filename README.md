# Life 

Life is a 2D game built with Godot Engine
.
It explores the theme of choices and consequences:

The player begins with little to no issues.

Then comes a choice:

Go down → The easy way, low risk, but with little to no reward at the end.

Go up → The risky way, full of challenges, but with bountiful rewards both during and at the end.

The essence of the game is to show that the path we choose defines the experience and outcome.

## Features

Simple but meaningful 2D gameplay.

Choice-driven design with consequences.

Built from scratch using Godot Engine.

## Tech Stack

Engine: Godot

Language: GDScript

Platform: 2D

## How to Play

Clone or download this repository.

Open the project in Godot Engine.

Run the game and make your choice: up or down.
